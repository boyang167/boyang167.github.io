0. 为什么要学 MCMC

MCMC = Monte Carlo + Markov Chain。名字里两个 MC 分别对应：

  1. 蒙特卡罗：用随机样本做期望/积分/求和的近似。
  2. 马尔科夫链：构造一条链，使其平稳分布等于目标分布 π，从而「走链」得到 π 的样本。

应用：分解机、RBM、贝叶斯推断、主题模型等，凡是要从复杂分布抽样或做期望近似，常会用到 MCMC。

学习顺序：先会 MC 求积分 → 再懂 Markov 链收敛 → 再学如何造转移矩阵（M-H / Gibbs）。

一、蒙特卡罗方法

1.1 问题：难算的积分

求 θ=∫ab​f(x)dx。若 f 的原函数不好求，可在 [a,b] 上随机取点，用样本均值近似：

θ≈nb−a​i=0∑n−1​f(xi​)

这隐含 x 在 [a,b] 上均匀。若 x 并不均匀，近似会偏得很厉害。

1.2 一般形式：重要性采样

若已知 x 的密度 p(x)（p(x)>0 在积分域上），则

θ=∫ab​f(x)dx=∫ab​p(x)f(x)​p(x)dx≈n1​i=0∑n−1​p(xi​)f(xi​)​,xi​∼p(x)

均匀分布时 p(x)=1/(b−a)，上式退化为 nb−a​∑f(xi​)。

关键：蒙特卡罗先要能从 p(x) 抽样。

1.3 常见分布怎么抽样

  • U(0,1) 易用（如线性同余）。
  • 许多连续/离散分布可由 U(0,1) 变换得到（如 Box–Muller 生成二维正态）。
  • NumPy / scikit-learn 等可直接采样常见分布。

困难：目标 p(x) 非常见分布时，不好直接采样。

1.4 接受-拒绝采样（Accept-Reject）

选易采样的 proposal q(x) 和常数 k，使 p(x)≤kq(x) 处处成立。

  1. 从 q 采 z0​；
  2. 从 U(0,kq(z0​)) 采 u；
  3. 若 u≤p(z0​) 则接受 z0​，否则拒绝，重复。

接受样本 z0​,…,zn−1​ 后，蒙特卡罗估计：

n1​i=0∑n−1​p(zi​)f(zi​)​

思路：用「好采的 q + 拒绝规则」模拟「难采的 p」。

1.5 蒙特卡罗仍不够用的场景

  1. 只有 p(x∣y)、p(y∣x)，联合 p(x,y) 难写 → 接受-拒绝不好设 q。
  2. 高维 p(x1​,…,xn​)，找合适的 q 和 k 很难。

→ 需要 马尔科夫链 来产生复杂分布的样本（下一篇）。

二、马尔科夫链

2.1 定义（一阶马尔科夫性）

P(Xt+1​∣Xt−2​,Xt−1​,Xt​,…)=P(Xt+1​∣Xt​)

转移概率 P(i,j)=P(Xt+1​=j∣Xt​=i) 组成矩阵 P。例：三状态股市模型

P=​0.90.150.25​0.0750.80.25​0.0250.050.5​​

（牛市 / 熊市 / 横盘，见原文维基示例图。）

2.2 平稳分布：与初值无关

设当前分布为行向量 π(t)，则 π(t+1)=π(t)P。

Pinard 用 P 数值实验：无论从 [0.3,0.4,0.3] 还是 [0.7,0.1,0.2] 出发，约 60 步后都趋于 [0.625,0.3125,0.0625]，与初始分布无关。

Pn 在 n≥6 后各行也稳定为该向量 → 与平稳分布一致。

结论（遍历链）：非周期、任意两状态连通时，limn→∞​Pijn​=π(j) 与 i 无关；π 满足

π(j)=i∑​π(i)P(i,j),πP=π,j∑​π(j)=1

π 称为平稳分布。离散、连续状态均成立（连续时用转移核）。

术语（原文解释）：

概念 含义
非周期 状态不按固定周期循环；对状态 i，d=gcd{n≥1:Piin​>0}，d=1 为非周期
连通 有限步可从任一状态到达任一状态

2.3 基于马尔科夫链的采样（若已知 P）

若已有平稳分布 π 对应的转移 P：

  1. 输入 P，burn-in 次数 n1​，样本数 n2​；
  2. 从简单分布采 x0​；
  3. 对 t=0,…,n1​+n2​−1：从 P(x∣xt​) 采 xt+1​；
  4. 丢弃前 n1​ 步，取 (xn1​​,…,xn1​+n2​−1​) 作为 π 的样本，用于蒙特卡罗。

遗留问题：给定目标 π，如何构造 P？→ MCMC / M-H / Gibbs。

三、MCMC 采样与 M-H 采样

3.1 细致平稳条件

对非周期链，若对所有 i,j：

π(i)P(i,j)=π(j)P(j,i)

则 π 是 P 的平稳分布（求和即 πP=π）。

随机选一个 Q 往往不满足 π(i)Q(i,j)=π(j)Q(j,i)。

3.2 MCMC：用接受率 α 修正 Q

引入 α(i,j)∈[0,1]，令

π(i)Q(i,j)α(i,j)=π(j)Q(j,i)α(j,i)

一种取法是 α(i,j)=π(j)Q(j,i)（未归一化到 1 的版本），定义

P(i,j)=Q(i,j)α(i,j)

与接受-拒绝采样类似：常见 Q + 接受/拒绝 → 目标 P。

MCMC 算法：

  1. 输入 Q、目标 π、n1​、n2​；
  2. 采 x0​；
  3. 对每步 t：
    • 从 Q(x∣xt​) 得候选 x∗​；
    • u∼U(0,1)；
    • 若 u<α(xt​,x∗​)=π(x∗​)Q(x∗​,xt​) 则 xt+1​=x∗​，否则 xt+1​=xt​；
  4. 取 burn-in 后的样本集。

缺点：α 可能很小（如 0.1），大量拒绝，n1​ 要极大，链难收敛。

3.3 M-H（Metropolis–Hastings）

在仍满足细致平稳的前提下，把接受率放大（不超过 1）：

α(i,j)=min{1, π(i)Q(i,j)π(j)Q(j,i)​}

M-H 算法（与 MCMC 相同框架，仅第 3 步 c 改用上式 α）。

若 Q 对称（Q(i,j)=Q(j,i)），则

α(i,j)=min{1, π(i)π(j)​}

→ 只需未归一化的 π 比值，不必算归一化常数。

3.4 M-H 小例子（原文）

目标：N(3,2)；提议：以当前点为均值、方差 1 的正态。对称 Q 下用 α=min(1,π(x∗​)/π(xt​))。代码见 mcmc_3_4.ipynb。

3.5 M-H 在高维下的两大难题（原文）

  1. π(i)Q(i,j)π(j)Q(j,i)​ 计算贵；α<1 时仍常拒绝。
  2. 联合 π(x1​,…,xd​) 难写，全条件 p(xi​∣x−i​) 好写。

→ Gibbs 采样（下一篇）。

四、Gibbs 采样

4.1 思路：用全条件分布当转移

二维 π(x1​,x2​)。固定 x1​=x1(1)​ 时，在直线 x1​=常数 上用条件分布 π(x2​∣x1(1)​) 作转移，可证任意两点满足细致平稳（原文由 π(A)π(x2(2)​∣x1(1)​)=π(B)π(x2(1)​∣x1(1)​) 推出）。
同理固定 x2​ 时用 π(x1​∣x2​)。

构造转移：只沿某一坐标轴移动，概率为对应全条件；跨轴移动概率为 0（单次只改一维）。

4.2 二维 Gibbs 流程

  1. 输入 π(x1​,x2​) 或 P(x2​∣x1​)、P(x1​∣x2​)，n1​、n2​；
  2. 随机初始化 (x1(0)​,x2(0)​)；
  3. 对 t=0,…,n1​+n2​−1：
    • 从 P(x2​∣x1(t)​) 采 x2(t+1)​；
    • 从 P(x1​∣x2(t+1)​) 采 x1(t+1)​；
  4. burn-in 后的二元组即为样本。

轨迹示意（坐标轴轮换）：

(x1(1)​,x2(1)​)→(x1(1)​,x2(2)​)→(x1(2)​,x2(2)​)→⋯

常用实现是轮换坐标轴；也可随机选轴，但轮换更常见。

4.3 多维 Gibbs

对 π(x1​,…,xn​)，每轮依次更新每一维：

xi(t+1)​∼P(xi​∣x1(t+1)​,…,xi−1(t+1)​,xi+1(t)​,…,xn(t)​)

与 坐标下降 类似：Lasso 固定 n−1 维求一维极值；Gibbs 固定 n−1 维对一维抽样。

4.4 二维正态实例（原文）

μ=(5,−1)，Σ=(11​14​)。用二元正态的闭式全条件 P(x1​∣x2​)、P(x2​∣x1​) 交替采样。代码见 mcmc_3_4.ipynb。

4.5 Gibbs 与 M-H 的关系（原文小结）

  • Gibbs 可视为 M-H 的特例：全条件作提议时接受率为 1，无需算 α，高维下更常用；Pinard 写「通常意义上的 MCMC 采样多指 Gibbs」，指的是工程实践中的主流，并非 MCMC 只有 Gibbs。
  • 至少二维才能「固定其余维、抽当前维」；一维仍用 M-H。
  • MCMC 系列闭环：Gibbs/M-H 产生 π 的样本 → 蒙特卡罗用样本做求和/期望。

信息论：熵、条件熵、互信息与交叉熵

离散随机变量为主（连续情形把求和换成积分，熵可能为微分熵）。默认对数底为 2（单位 bit）；底为 e 时为 nat。差一个常数因子，大小关系与推导不变。

1. 熵（Entropy）

定义：随机变量 X 的分布 p(x)=P(X=x) 的 Shannon 熵

H(X)=−x∑​p(x)logp(x)=EX∼p​[−logp(X)]

含义：按最优编码，平均每个 outcome 至少需要 H(X) bit 才能无损描述 X；也是不确定性的度量——分布越「平」，熵越大。

性质（常用）

性质 公式 / 说明
非负 H(X)≥0
确定性 若某 x0​ 满足 p(x0​)=1，则 H(X)=0
上界 ∣X∣=n 时，H(X)≤logn，等号当且仅当均匀分布
链式（多变量） H(X1​,…,Xn​)=∑i​H(Xi​∣X1​,…,Xi−1​)

二元熵（抛硬币）：H(X)=−plogp−(1−p)log(1−p)，在 p=0.5 取最大 log2。

2. 联合熵与条件熵

联合熵

H(X,Y)=−x,y∑​p(x,y)logp(x,y)

条件熵：已知 X 后，Y 还剩多少不确定性

H(Y∣X)=x∑​p(x)H(Y∣X=x)=−x,y∑​p(x,y)logp(y∣x)

其中 H(Y∣X=x)=−∑y​p(y∣x)logp(y∣x)。

核心恒等式

H(X,Y)=H(X)+H(Y∣X)=H(Y)+H(X∣Y)

读法：Y 的总不确定性 = X 的不确定 + 给定 X 后 Y 仍不确定的部分。条件熵 不会 大于边际熵：H(Y∣X)≤H(Y)（知道 X 不会增加对 Y 的不确定）。

例：X 为天气，Y 为是否带伞。H(Y∣X) 通常远小于 H(Y)，因为天气强预测是否带伞。

3. 互信息（Mutual Information）

定义

I(X;Y)=H(X)−H(X∣Y)=H(Y)−H(Y∣X)=H(X)+H(Y)−H(X,Y)

含义：X 与 Y 共享的信息量；知道 Y 能平均减少多少关于 X 的不确定性（对称）。

与 KL 散度：若 p(x,y) 为真联合，p(x)p(y) 为独立假设下的联合，则

I(X;Y)=DKL​(p(x,y)∥p(x)p(y))≥0

等号当且仅当 X 与 Y 独立。

性质

  • I(X;Y)=I(Y;X)≥0
  • 独立 ⇒I(X;Y)=0（离散情形逆命题也成立）
  • 数据处理不等式：X→Y→Z 形成 Markov 链时，I(X;Z)≤I(X;Y)

与机器学习

场景 关系
决策树 ID3 分裂特征 A 的 信息增益 =I(Y;A)=H(Y)−H(Y∣A)
特征选择 最大化 I(Y;Xj​) 或条件互信息 I(Y;Xj​∣X−j​)
聚类 / 表示学习 希望表示 Z 保留关于输入的信息：I(X;Z) 大

4. 交叉熵（Cross-Entropy）

定义：真实分布 p，模型或近似分布 q（同一支撑上 q(x)>0）

H(p,q)=−x∑​p(x)logq(x)=EX∼p​[−logq(X)]

不是对称的：一般 H(p,q)=H(q,p)。

与熵、KL 的关系

H(p,q)=H(p)+DKL​(p∥q)
  • H(p)：用 p 自己的编码长度（理论下界）。
  • DKL​(p∥q)≥0：用 q 去编码 p 的额外代价；p=q 时为 0。
  • 因此 H(p,q)≥H(p)，等号当且仅当 p=q（几乎处处）。

相对熵（KL 散度）

DKL​(p∥q)=x∑​p(x)logq(x)p(x)​=H(p,q)−H(p)

（p 固定时，最小化交叉熵等价于最小化 KL。）

5. 四者关系一图

        H(X,Y)
       /      \
   H(X)        H(Y)
       \      /
    I(X;Y) = H(X)-H(X|Y) = H(Y)-H(Y|X)

条件：H(X,Y) = H(X)+H(Y|X)

交叉熵（固定真实 p）：
H(p,q) = H(p) + KL(p||q)  ≥  H(p)

6. 分类损失：为何常用交叉熵

多类标签 one-hot 为 p（真实类 k 上 p(k)=1，其余为 0），模型输出 softmax 为 qθ​。样本损失

ℓ=−logqθ​(y)=H(p,qθ​)

对 p 为 one-hot 时，H(p)=0，故最小化交叉熵 = 最小化 DKL​(p∥qθ​)。在 i.i.d. 假设下，最小化训练集平均交叉熵等价于极大似然（见 2-machine-learning.md 面试题 §7）。

与互信息的联系（直观）：好的分类器让 qθ​(y∣x) 接近 p(y∣x)，等价于在给定 x 下减少 Y 的条件熵；特征 X 与标签 Y 的互信息 I(X;Y) 给出了「可预测性」的上界。

7. 交叉熵之外：训练里常见的「熵系」目标

交叉熵解决的是：固定真实分布 p，让模型 qθ​ 去逼近 p（等价于最小化 DKL​(p∥qθ​)）。工程里还会用到下面几类——有的仍是交叉熵/ KL 的变体，有的是最大化熵或最大化互信息。

7.1 与交叉熵等价或只差常数

名称 形式 说明
负对数似然 NLL −logqθ​(y∣x) one-hot 分类时与单样本交叉熵相同
最小化 KL DKL​(p∥qθ​) p 固定时 =H(p,qθ​)−H(p)，优化方向与 CE 一致
二元交叉熵 BCE −ylogq−(1−y)log(1−q) 多标签 / 二分类 sigmoid；仍是「真实 Bernoulli p vs 模型 q」的 CE

7.2 交叉熵的「改进版」（仍基于 H(p,q)）

标签平滑（Label Smoothing）
把 one-hot 换成软标签 p​(k)=(1−ε)1k=y​+ε/K，最小化 H(p​,qθ​)。
效果：防止 logits 过于自信，等价于给目标分布人为加一点熵。

类别加权 / Focal Loss
加权 CE：−wy​logqθ​(y)；Focal：−(1−qθ​(y))γlogqθ​(y)。
不是新熵定义，而是重加权困难样本；思想来自类别不平衡（笔记里的 Focal Loss）。

知识蒸馏
用教师分布 pT​（软标签）代替 one-hot：H(pT​,qS​)。
学生拟合的是高熵的软目标，而不只是 0/1。

Softmax + 温度
qi​∝exp(zi​/T)，T>1 时分布更平、熵更大，蒸馏/校准常用。

7.3 用「对称 / 有界」散度代替单向 KL

散度 定义（离散） 特点
KL DKL​(p∥q) ∑plog(p/q) 与 CE 一体；不对称，q→0 且 p>0 时爆炸
反向 KL DKL​(q∥p) ∑qlog(q/p) mode-seeking vs forward KL 的 mean-seeking（生成模型里两种 ELBO 取向）
JS 散度 21​DKL​(p∥m)+21​DKL​(q∥m)，m=2p+q​ 对称，有界 [0,log2]（log 底 2）；GAN 早期 JSD 与 MLE 的桥梁

优化时：p 固定 → 最小化 CE / forward KL 最常见；需要对称或稳定训练时再考虑 JS 等。

7.4 最大化熵（MaxEnt）与熵正则

场景 目标 含义
最大熵模型 在约束 Ep​[fj​(x)] 下 最大化 H(p) 得到指数族 p(x)∝exp(∑λj​fj​(x))；与 MEM 笔记一致
策略熵奖励（RL） J=E[R]+βH(π(⋅∣s)) 鼓励探索，避免策略过早塌缩到确定性
置信度惩罚 训练分类器时 最大化 预测熵 H(qθ​)（或等价正则） 与 label smoothing 类似，抑制过拟合

这里是越大越好的熵项，与「最小化交叉熵」方向相反，常作为正则项加在损失里。

7.5 最大化互信息（不是交叉熵，但同属信息论优化）

方法 思想
InfoNCE / 对比学习 用噪声对比估计 I(X;Z) 的下界；正样本对拉近、负样本推远
VAE 的 ELBO E[logp(x∣z)]−DKL​(q(z∣x)∥p(z))：重建项 + 对 latent 的 KL（约束后验不要偏离先验太远）
IB / 深度 IB 在 I(X;Y) 与压缩 I(X;Z) 之间折中

7.6 广义熵（理论扩展，优化较少直接用）

Rényi 熵 Hα​(X)=1−α1​log∑x​p(x)α：α→1 退化为 Shannon 熵。
Tsallis 熵 Sq​=q−11−∑pq​：非广延系统、部分物理统计用。
机器学习主流程里 Shannon 熵 + KL/CE 仍占绝对多数；Rényi 在聚类、信息瓶颈推广里偶尔出现。

7.7 怎么选（速记）

分类默认     → 交叉熵 / NLL（= 最小化 KL(p||q)）
过自信/不平衡 → label smoothing、加权 CE、Focal
软标签/蒸馏   → H(p_teacher, q_student)
探索/先验     → 最大化 H(π) 或 MaxEnt 约束
表示学习     → 最大化 I(X;Z)（InfoNCE 等）
要对称散度   → JS（或 Wasserstein 等，已非熵）

8. 自测

  • 证明 H(Y∣X)≤H(Y)
  • 证明 I(X;Y)=0 当且仅当 X,Y 独立（离散）
  • 对二元变量手算 H(X)、H(Y∣X)、I(X;Y)
  • 说明：为何 ID3 选「信息增益最大」的特征等价于 I(Y;A) 最大
  • 比较：最小化 H(p,q) 与最小化 DKL​(q∥p) 在生成模型里行为差异（mode vs mean）
