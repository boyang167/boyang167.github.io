## The real interface is meaning

A data agent needs more than table names. It needs metric definitions, allowed joins, ownership and examples of how business language maps to the data model.

## Put guardrails before generation

Constrain accessible sources, inspect generated SQL, set cost limits, and return the query with every answer.
