## Model for the decision

A useful model does not only minimize error. It should answer a process question: which operating range is safe, which variables matter most, and where uncertainty is too high.

## Hybrid models are practical

Mechanistic constraints provide interpretable structure. Machine learning can capture residual effects when process data is representative.
