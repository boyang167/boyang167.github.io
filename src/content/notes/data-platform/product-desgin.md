# 平台愿景

构建一个集规划、开发、部署、运维于一体的智能DevOps平台，通过多租户隔离和四级数据模型，为企业提供安全、高效、可扩展的软件交付解决方案

# 多租户DevOps平台角色权限矩阵

## 用户角色定义

### 1. 系统管理员 (System Admin)

- 负责平台整体管理和租户创建
- 拥有最高权限，可以管理所有租户

### 2. 租户管理员 (Tenant Admin)

- 管理单个租户内的所有资源
- 负责租户成员管理和权限分配

### 3. 产品经理 (Product Manager)

- 负责产品规划和需求管理
- 管理产品下的项目和发布计划

### 4. 开发工程师 (Developer)

- 负责项目开发和代码提交
- 参与代码审核和发布流程

### 5. 运维工程师 (DevOps Engineer)

- 负责项目部署和运维监控
- 管理集群配置和存储资源

## 符号说明

* ✅：完全权限
* ⚠️：受限权限（根据具体范围）
* ❌：无权限

这个权限矩阵确保了：

1. **职责分离** ：每个角色有明确的权限边界
2. **最小权限原则** ：用户仅获得工作必需的最小权限
3. **层级控制** ：权限按平台→租户→业务线→产品→项目逐级细化
4. **安全合规** ：敏感操作受到严格管控
5. **灵活协作** ：在安全前提下支持团队协作

# User journey 

## 完整用户旅程

### 阶段一：平台初始化与租户创建

#### 1.1 系统管理员首次登录

**用户**: 系统管理员

**目标**: 初始化平台并创建第一个租户

**操作流程**:

1.**登录系统**

- 访问平台登录页面
- 使用系统管理员账号登录
- 进入系统管理控制台

2.**创建租户**

- 进入"租户管理"模块
- 点击"创建租户"按钮
- 填写租户信息：

  - 租户代码：`company-a`
  - 租户名称：`A公司`
  - 描述：`A公司的DevOps租户`
  - 最大用户数：100
  - 最大项目数：50
  - 最大产品数：20
  - 最大业务线数：10
- 设置租户状态为"活跃"
- 保存租户信息

3.**邀请租户管理员**

- 在租户详情页面添加成员
- 邀请用户并分配"租户管理员"角色
- 发送邀请邮件

**预期结果**: 成功创建租户并邀请管理员

#### 1.2 租户管理员首次登录

**用户**: 租户管理员

**目标**: 进入租户并完成初始配置

**操作流程**:

1.**接收邀请并登录**

- 收到邀请邮件
- 点击邮件链接注册账号
- 使用新账号登录系统

2.**选择租户**

- 登录后进入租户选择页面
- 选择"A公司"租户
- 确认进入租户工作空间

3.**租户信息确认**

- 查看租户基本信息
- 确认资源限制和使用情况
- 了解当前租户状态

**预期结果**: 成功进入租户工作空间

### 阶段二：业务线与产品规划

#### 2.1 创建业务线

**用户**: 租户管理员

**目标**: 为租户创建业务线结构

**操作流程**:

1.**进入业务线管理**

- 导航到"业务线管理"模块
- 查看当前业务线列表（为空）

2.**创建业务线**

- 点击"创建业务线"按钮
- 填写业务线信息：

  - 业务线名称：`电商业务线`
  - 业务线代码：`ecommerce`
  - 描述：`负责电商平台相关产品开发`
  - 负责人：选择产品经理
- 保存业务线信息

3.**创建更多业务线**

- 重复上述步骤创建：

  -`移动业务线` (mobile)

  -`数据业务线` (data)

**预期结果**: 成功创建3个业务线

#### 2.2 产品规划与管理

**用户**: 产品经理

**目标**: 在业务线下创建和管理产品

**操作流程**:

1.**进入产品管理**

- 选择"电商业务线"
- 进入"产品管理"模块
- 查看产品列表

2.**创建产品**

- 点击"创建产品"按钮
- 填写产品信息：

  - 产品名称：`用户管理系统`
  - 产品代码：`user-management`
  - 版本：`1.0.0`
  - 描述：`负责用户注册、登录、权限管理等功能`
  - 可见性：`组内`
  - 产品组：`核心系统组`
- 保存产品信息

3.**设置产品权限**

- 进入产品详情页面
- 在"权限管理"标签页
- 为开发团队授予"读写"权限
- 为测试团队授予"只读"权限

4.**创建更多产品**

- 重复创建：

  -`订单管理系统` (order-management)

  -`支付系统` (payment-system)

  -`商品管理系统` (product-management)

**预期结果**: 在电商业务线下成功创建4个产品

### 阶段三：项目管理与开发

#### 3.1 项目创建与配置

**用户**: 开发工程师

**目标**: 在产品下创建开发项目

**操作流程**:

1.**进入项目管理**

- 选择"用户管理系统"产品
- 进入"项目管理"模块
- 查看项目列表

2.**创建项目**

- 点击"创建项目"按钮
- 填写项目信息：

  - 项目名称：`user-service`
  - 显示名称：`用户服务`
  - 命名空间：`ecommerce-user`
  - 语言：`Java`
  - 描述：`用户服务的后端API项目`
  - Git地址：`https://git.company.com/ecommerce/user-service.git`
  - 构建路径：`/`
- 保存项目信息

3.**配置项目模板**

- 进入项目详情页面
- 选择"配置与存储"标签
- 配置部署模板：

  - 资源类型：`Deployment`
  - 副本数：3
  - 端口：8080
  - 资源配置：CPU 500m, Memory 1Gi
- 保存模板配置

4.**配置存储和配置**

- 创建存储类：`fast-ssd`
- 创建PVC：`user-service-pvc`
- 配置ConfigMap：`user-service-config`
- 设置环境变量和配置文件

**预期结果**: 成功创建项目并完成基础配置

#### 3.2 开发与代码管理

**用户**: 开发工程师

**目标**: 进行项目开发和代码提交

**操作流程**:

1.**代码开发**

- 克隆项目代码到本地
- 创建功能分支：`feature/user-login`
- 开发用户登录功能
- 提交代码到Git仓库

2.**创建Pull Request**

- 在Git平台创建PR
- 关联到项目需求
- 请求代码审核

3.**AI代码审核**

- 系统自动触发AI代码审核
- AI分析代码变更：

  - 代码质量检查
  - 安全漏洞扫描
  - 性能优化建议
  - 最佳实践检查
- 生成审核报告

4.**人工代码审核**

- 审核人员查看AI审核结果
- 进行人工代码审核
- 提出修改建议
- 批准或拒绝PR

**预期结果**: 完成代码开发和审核流程

### 阶段四：构建与部署

### 阶段五：监控与运维

## 关键功能亮点

### 1. 多租户隔离

-**数据隔离**: 通过tenant_id确保不同租户数据完全隔离

-**权限隔离**: 每个租户拥有独立的权限体系

-**资源隔离**: 租户间资源使用互不影响

### 2. 四级数据模型

-**租户**: 最高级别的组织单位

-**业务线**: 租户下的业务分组

-**产品**: 业务线下的产品分组

-**项目**: 产品下的具体开发项目

### 3. AI代码审核

-**自动化审核**: 基于AI的代码质量检查

-**多维度分析**: 安全性、性能、最佳实践

-**智能建议**: 提供代码优化建议

-**审核报告**: 生成详细的审核报告

### 4. 完整DevOps流程

-**代码管理**: Git集成和分支管理

-**构建部署**: Jenkins集成和自动化部署

-**监控运维**: 实时监控和告警管理

-**发布管理**: 版本管理和发布流程

### 5. 权限管理

-**RBAC模型**: 基于角色的权限控制

-**细粒度权限**: 资源级别的权限管理

-**动态权限**: 支持权限的动态分配和撤销

-**审计日志**: 完整的操作审计记录
