---
title: Multi-Agent Design Checklist
description: A compact checklist for choosing roles, handoffs and evaluation points in multi-agent systems.
date: 2026-10-08
area: AI Agent
tags: [Multi-Agent, Evaluation, Workflow]
---
- Give each agent one stable responsibility.
- Make handoffs explicit and structured.
- Use shared state only when its owner is clear.
- Evaluate the workflow end to end, not only individual prompts.
