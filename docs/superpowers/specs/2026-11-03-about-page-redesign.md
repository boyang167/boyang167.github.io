# 关于我页面整体优化设计

## 目标

将 `/about/` 优化为个人技术品牌入口，让访客快速理解 Boyang Wang 的复合技术能力、CMC 行业深度、工程方法和代表成果。

页面采用“首屏精炼、下方渐进展开”的信息策略，保留现有完整内容，但降低首屏与能力区的阅读负担。

## 设计原则

- 编辑式叙事与工程系统感结合。
- 以内容层级和可信成果为中心，避免装饰性堆叠。
- 保持低饱和背景、蓝色强调、充足留白和轻量卡片。
- 每个区块只承担一个明确叙事任务。
- 桌面端建立稳定双栏与横向节奏；移动端回归自然单栏。
- 保持现有中英文切换、深色模式和静态站点架构。

## 页面结构

### 1. 首屏品牌定位

- 左侧展示姓名、复合型数据科学家定位和两段专业简介。
- 精简标签，只保留 Agent Engineering、Data Platform、CMC、ML / DL 等关键领域。
- 保留“与我交流”和“阅读博客”两个主要入口。
- 右侧使用 `AI × Data × CMC` 品牌卡，包含结构图标、英文副标题、Engineering Intelligence 标签，以及 `Curious by nature. Engineer by practice.`。
- 控制首屏高度，确保桌面端能同时看到下一模块开头。

### 2. 四个领域支柱

将原有统计条重构为四个清晰支柱：

1. Agent Engineering
2. Data Platform
3. Machine Learning / Deep Learning
4. CMC Digitalization

每项使用短标题与一句价值描述，不展示无意义数字。

### 3. 技术能力

- 保留现有六个能力领域及详细技术项。
- 使用更清晰的序号、标题、摘要和分组结构。
- 首要突出 Agent Engineering、Data Platform、ML / DL 和 Platform Engineering。
- Math 与 Full-Stack 作为支撑能力降低视觉权重。
- 通过留白、分隔线和浅色背景形成渐进阅读，不制造密集卡片墙。

### 4. 价值方法

将三个原则组织为横向流程：

`领域知识可计算化 → 可信 Agent 系统 → 工程化产品交付`

桌面端横向排列并使用轻量连接线，移动端改为纵向流程。每一步保留标题、引导句和说明。

### 5. 经历与教育

- 保留现有经历和教育内容。
- 强化年份、角色、主题和成果之间的层级。
- 代表项目与可量化成果优先显示，背景描述次之。
- 时间线保持简洁，不使用过重装饰。

### 6. 内容与联系

- 合并页面尾部重复的内容分享与联系表达。
- 左侧说明持续公开的内容方向，右侧提供博客、知识库、GitHub 与联系入口。
- 使用一个明确的收尾 CTA，避免多层卡片。

## 视觉系统

- 主背景沿用现有浅灰蓝。
- 品牌蓝用于标题重点、序号、链接和关键图标。
- 内容卡片采用 16–24px 圆角、细边框和低强度阴影。
- 标题层级使用紧凑字距；正文保持舒适行高和有限行宽。
- 区块间距明显大于卡片内部间距，建立页面节奏。
- 深色模式保持相同层级关系，避免简单反色。

## 响应式设计

- 大于 960px：首屏双栏，能力与方法区采用多栏。
- 760–960px：首屏比例收窄，能力区改为两栏。
- 小于 760px：品牌卡置于文字前，所有模块单栏，缩减标题字号与外边距。
- 任何宽度下不得出现横向滚动、文字截断或按钮溢出。

## 实现约束

- 主要修改 `src/pages/about.astro`。
- 仅在新增或修改中英文文案时更新 `src/layouts/BaseLayout.astro`。
- 不引入新的 JavaScript 框架、组件库或运行时依赖。
- 保持现有链接、导航、内容来源与 Astro 静态输出。

## 验证标准

- `npm run build` 成功。
- 页面无新增 lint 或语法错误。
- 浏览器验证桌面端和移动端首屏、能力区、经历区及底部 CTA。
- 中文与英文切换后不出现未翻译的新文案。
- 浅色与深色模式下均具备清晰对比度。
- 页面结构语义清晰，标题顺序合理，交互元素可访问。
