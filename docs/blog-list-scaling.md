# 博客列表：文章变多时的策略

## 目标

- 静态站点（Astro SSG），无数据库。
- 保留 **全库分类筛选 + 搜索**。
- 首屏轻量，长列表可扫、可渐进展开。
- 与现有 `raw/3-blog` + Content Collections 一致。

## 分层策略

| 规模 | 做法 |
|------|------|
| **≤10 篇** | 单页全部展示，无分页控件。 |
| **11～约 80 篇** | 首屏 **10 条** + **加载更多**（客户端，步长 10）；**全部** 且无搜索时按 **年份** 分组标题。 |
| **80+ 篇** | 同上 + 建议启用 **静态分页路由** `/blog/page/2/`（见下），减轻单页 HTML 体积；筛选仍可用构建期注入的 JSON 索引（可选后续）。 |
| **200+ 篇** | 静态分页为主路径；列表页只渲染当页条目；全库 metadata 独立 `blog-index.json` 供搜索（可选）。 |

## 当前实现（第一阶段）

- 常量：`src/lib/blog.ts` → `BLOG_LIST_PAGE_SIZE = 10`（**第 11 篇起**分页）。
- `/blog/` 构建时输出 **全部** 文章 DOM（利于 SEO 与无 JS），默认 **隐藏** 超出首屏的条目（`hidden` + 脚本展开）。
- 筛选 / 搜索后：在匹配结果上重新分页，并重置到第 1 页。
- 年份分隔：仅在「全部 + 无搜索」时显示，避免筛选态下空年份标题。

## 可选第二阶段：静态分页

- 新增 `src/pages/blog/page/[page].astro`。
- `getStaticPaths`：`page` 从 2 到 `blogListPageCount(n)`。
- 第 1 页仍为 `/blog/`；页脚链到相邻页（利于爬虫，不依赖 JS）。

## 写作约定（可选）

- 长文保持 `readTime` 准确；系列文用同 `category` 与内链。
- 归档年久文章不必改 slug；URL 稳定优先于目录整理。
